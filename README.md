## Task 1: Rule-Based Chatbot (chatbot.py)

**Objective:** Build a simple chatbot that can respond to user inputs based on predefined rules.

**Features:**
- Responds to greetings like Hello, Hi
- Answers questions like "How are you?", "What is your name?"
- Provides information about Python and Internship
- Simple pattern matching using if-else logic
- User-friendly console interaction

**How to Run:**
1. Run the file: `python chatbot.py`
2. Start chatting with the bot
3. Type 'bye' to exit

**Tech Stack:** Python

## Task 3: Real-Time Face Detection (face_detection.py & live_camera.py)

**Objective:** Build a system that detects human faces in images and live webcam feed using OpenCV Haar Cascade.

**Features:**
- Detects multiple faces in a group photo (7 faces detected)
- Real-time face detection via webcam
- Draws green bounding boxes around faces
- Saves output as `output.jpg`

**How to Run:**
1. Install: `pip install opencv-python==4.10.0.84`
2. For Image: `python face_detection.py`
3. For Live Camera: `python live_camera.py` (press 'q' to exit)

**Tech Stack:** Python, OpenCV
