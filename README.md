# CODSOFT - Artificial Intelligence Internship

This repository contains all tasks completed as part of my AI Internship at CodSoft.

## Task 1: Rule-Based Chatbot (chatbot.py)

**Objective:** Build a simple chatbot that can respond to user inputs based on predefined rules.

**Features:**
- Responds to greetings like Hello, Hi
- Answers questions like "How are you?", "What is your name?"
- Provides information about Python and Internship
- Simple pattern matching using if-else logic
- User-friendly console interaction

**How to Run:**
1. Run the file: `python chatbot.py`
2. Start chatting with the bot
3. Type 'bye' to exit

**Tech Stack:** Python
